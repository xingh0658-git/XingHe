星河桌寵 使用說明
==================

【啟動】（關掉之後想再打開，也是這樣）
最簡單：按 ⌘ 空白鍵打開 Spotlight，輸入「星河」，按 Enter。
‧「星河」App 放在你的「應用程式」資料夾（~/Applications），也可以把它拖到 Dock，之後點一下就打開。
‧第一次打開時，macOS 可能會問「星河」想要取用「桌面」檔案夾，按「允許」。
  如果不小心按了「不允許」：打開「系統設定」→「隱私權與安全性」→「檔案與檔案夾」，找到「星河」，把「桌面」打開，再打開星河一次。
‧也可以雙擊這個資料夾裡的「啟動星河.command」（會跳出一個終端機視窗，看到「星河已經在背景啟動了」就可以關掉）。
‧星河會出現在螢幕右下角，選單列（螢幕最上面）也會多一個星星圖示。星河已經開著的話，會把他叫到你面前。
‧如果 macOS 說「無法打開」：打開「系統設定」→「隱私權與安全性」，往下找到「啟動星河.command」，按「強制打開」，再雙擊一次。

【設定 API 金鑰】（第一次啟動會自動跳出設定視窗）
1. 按「打開 Claude Console」，登入你的 Claude 帳號(https://platform.claude.com/)
2. 到「API Keys」建立一把新的金鑰，然後按複製
3. 回到設定視窗按「從剪貼簿貼上」→ 選擇模型 → 按「儲存」
   （設定視窗被瀏覽器蓋住、找不到的話：對星河按右鍵 →「設定…」，或按選單列的星星 →「設定…」）
‧之後想換金鑰或模型：對星河按右鍵 →「設定…」
‧語言：設定視窗右上角可以切換「國語 / English」，按了馬上換。選 English 時，星河會說英文，設定視窗和選單也都是英文；選國語時，星河照常用台灣國語說話。
‧金鑰只存在你這台電腦裡。使用 API 需要先在 Claude Console 儲值，聊天會依用量計費。
‧模型：Sonnet 5.5（推薦）、Haiku 5.5（最省）、Opus 5.5（最聰明）、Fable 5.1（最新）
‧努力程度：低／中／高／超高／Max，越高想得越仔細，但比較慢、也比較貴。
‧速度：「快速」只有 Opus 5.5 能用（Fable 5.1 目前還不支援），回覆比較快，但 API 費用是標準的 2 倍；帳號要先向 Anthropic 申請開通。
‧最大 Token 數：星河每次回覆的上限（思考用掉的也算），最多 128,000（沒辦法無限）。努力程度調高時星河會自動放寬；操作電腦的工作不受這個限制。

【怎麼跟星河玩】
‧點一下星河：卡片會轉一圈，然後打開聊天框。打字後按 Enter 送出，按 Esc 關閉。
‧給星河看圖片：
  按聊天框左邊的圖片按鈕選圖片（照片、截圖、HEIC 都可以）；
  或在聊天框按 ⌘V 貼上（例如按 ⌘ Control Shift 4 拷貝的截圖、網頁上拷貝的圖片、Finder 裡拷貝的圖片檔）；
  也可以把圖片拖到聊天框。
  一次最多 4 張，可以只傳圖片不打字。點一下小圖就能拿掉。
  圖片會先縮小再送出（比較省錢）；之後的兩三句話星河都還看得到，再久就只記得「你傳過圖片」。
  圖片存在 ~/Library/Application Support/星河/images，「清除對話記憶」時會一起刪掉。
‧按住星河拖曳：可以把他移到螢幕上的任何地方（最上面、角落都可以），下次開啟會記得位置。
  放在螢幕最上面時，泡泡和聊天框會自動改到星河下面；放在最下面時會改到上面。
‧星河的大小：到設定拖動「大小」，最小 50%、最大 200%，拖動時馬上看得到效果，按「儲存」才會記住。
‧看影片全螢幕時：瀏覽器（Chrome、Safari 等）或影片播放器全螢幕時，星河會自動躲起來，離開全螢幕就回來。
  其他 App 全螢幕（例如 Claude）不會躲。到設定的「全螢幕時自動隱藏星河」可以改成「任何 App 全螢幕時」或「不要隱藏」。
  在全螢幕時想叫星河出來：按選單列的星星 →「顯示星河」，切換桌面之前他都不會再躲。
‧星河是活的：會眨眼、呼吸、偶爾抖抖耳朵；睡著時眼睛會閉起來。
  他說話時身體會跟著動：台詞裡有（搖尾巴）就真的搖、（歪著頭）就歪頭、（蹭蹭）會冒愛心、（哈欠）會閉眼伸懶腰。
  閒著沒事時，他會自己東張西望、伸懶腰、打哈欠，每幾分鐘還會在桌面上散步一小段（設定裡的「讓星河自己在桌面上散步」可以關掉；散步不會改掉你放他的位置）。
‧摸摸頭：滑鼠在他頭上左右來回摸（不用按），他會瞇起眼睛、臉紅、冒愛心，偶爾說一句話。
‧對星河按右鍵：跟星河聊天、設定、安靜模式、清除對話記憶、結束。
‧選單列的星星：星河不見了的話，按「叫星河回來」，他會回到右下角。
‧星河每 10~20 分鐘會說一句關心你的話（開啟安靜模式就不會說）。
‧你離開電腦 15 分鐘，星河會打瞌睡；你回來時，他會跟你打招呼。
‧星河的記憶沒有上限：聊超過 60 句時，星河會把比較舊的對話整理成重點記下來（用便宜的 Haiku 模型，花費很少），聊再久也記得以前的事。
‧「清除對話記憶」會把對話和整理好的重點一起刪掉。

【讓星河看你在做什麼】
‧星河會每隔一陣子偷看一眼你的螢幕（截一張圖給 Claude 看），看到有趣的、想關心的事才會說一句，大部分時候只是看看。
‧到設定的「讓星河看你在做什麼」可以選：不看／偶爾看（約每 10～15 分鐘）／常常看（約每 5 分鐘）。
‧第一次會需要 macOS 的「螢幕錄製」權限：系統會跳出詢問，按「允許」之後要重新打開星河一次。
  沒跳出來或按錯了：「系統設定」→「隱私權與安全性」→「螢幕錄製」，把「星河」打開，再重新打開星河。
‧隱私：
  你在輸入密碼（macOS 的安全輸入模式）、用密碼管理員、系統設定、錢包或銀行的 App，或視窗標題像是登入、付款、驗證碼、電話號碼、身分證、無痕視窗時，星河完全不會截圖。
  就算截了圖，星河的規則也是：畫面上有密碼、付款、訊息內容之類的東西就當作沒看到。
  截圖只放在記憶體裡看一眼，不會存檔，也不會留在對話紀錄裡；對話裡只記一句「看到爸爸在做什麼」（不含名字、數字、網址）。
  安靜模式開著、你離開電腦、聊天框開著、星河躲起來的時候都不會看。
‧費用：用 API 計費，「偶爾看」一天大約 1 美元（約 NT$30），「常常看」大約 2 美元。選「不看」就不會花錢。

【讓星河幫你操作電腦】
‧直接跟星河說要在電腦上做什麼，例如「幫我打開 Safari」、「把桌面的截圖收到一個叫『截圖』的資料夾」。
‧星河會交給 Claude Code 自動完成，做完會告訴你結果。這是「完全自動」：他會直接動手，不會先問你，請只交代你確定要做的事。
‧做到一半想停：對星河按右鍵 →「停止星河正在做的事」。
‧第一次操作某個 App 時，macOS 可能會問「要允許控制…嗎？」，按「好」才能繼續。
‧不想讓他動電腦：到設定把「讓星河幫我操作電腦」取消勾選。
‧需要電腦上有 Claude 桌面 App（星河會用它附的 Claude Code）。

【Claude 額度用完時，請星河接手】
‧你和 Claude（Claude App 的 Code 分頁）做到一半、Claude 的額度用完了，可以請星河用 API 接著做。
‧跟星河說要接手哪一個對話，下面三種都可以：
  給他那個對話的截圖（看得到上面的標題就好）；
  給他專案的 GitHub 網址，或說資料夾的名字；
  直接說對話的標題，例如「幫我繼續『星河 macOS 桌寵程式』」。
  再告訴他要繼續做什麼；只說「繼續」的話，他會照之前的計畫做下去。
‧星河會帶著那個對話的完整內容、在同一個資料夾繼續做，做完告訴你結果。
  原本的對話不會被改動；額度恢復後，你回到 Claude App 照常繼續就好。
  （星河做的修改都在資料夾裡，回去時可以跟 Claude 說「星河剛剛幫我做了一些修改，你看一下」。）
‧同一個對話再請星河接手，他會接著上次做到的地方。
‧費用：用的是 API 額度，對話越長越貴。很長的對話（例如做星河的這個對話），用 Opus 5.5 做一件事大約要 3～10 美元。
‧需要先勾選設定裡的「讓星河幫我操作電腦」。

【用 Claude 帳號登入】
‧沒有 API 金鑰，或 API 額度用完時，星河會改用你 Claude 帳號的額度繼續聊天和做事（設定裡可以關掉）。
‧要先登入一次：對星河按右鍵 →「設定…」→ 按「登入 Claude」，在打開的瀏覽器用你的 Claude 帳號登入。
‧用 Claude 帳號時不會開快速模式，避免額外費用。

【結束】
對星河按右鍵 →「結束」，或按選單列的星星 →「結束」。

【其他】
‧桌面上的「星河桌寵」資料夾已經藏起來了（星河照常可以用）。想再看到它：
  在 Finder 按 ⌘ Shift .（句號）就會顯示藏起來的東西，再按一次又會藏回去；
  或在 Finder 選「前往」→「前往檔案夾…」，輸入 ~/Desktop/星河桌寵 再按 Enter。
‧設定和對話記憶存放在：~/Library/Application Support/星河/（星河偷看螢幕的截圖不會存在這裡，也不會存在任何地方）
‧執行紀錄（出問題時可以看）：~/Library/Logs/星河桌寵.log
‧不想用了：先結束星河，再把整個「星河桌寵」資料夾丟到垃圾桶。
