星河的設定

貼上 Claude API 金鑰，星河就能跟你聊天囉！

  1. 按「打開 Claude Console」，登入你的帳號
  2. 到「API Keys」建立一把新的金鑰，按複製
  3. 回到這裡按「從剪貼簿貼上」，再按「儲存」

找不到這個視窗的話：對星河按右鍵 →「設定…」，或按螢幕最上面選單列的星星 →「設定…」

星河每次回覆的上限（思考用掉的也算），最多 128,000（沒辦法無限）。努力程度調高時星河會自動放寬；操作電腦的工作不受這個限制。

電腦控制與 Claude 帳號

檢查 Claude Code 中…

星河會把你交代的事交給 Claude Code 自動完成，做完再告訴你結果。做到一半想停：對星河按右鍵 →「停止星河正在做的事」。

Claude 帳號要先登入一次：按「登入 Claude」，在打開的瀏覽器登入你的 Claude 帳號。用 Claude 帳號時不會開快速模式。
